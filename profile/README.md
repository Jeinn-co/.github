# Jeinn

SaaS 開發商，專精 AI 整合落地的建置服務。

我們把 AI 從概念變成真的在跑的產品功能 — 不是 demo，是能上線、能維護、能交付給團隊繼續開發的系統。

## 我們做什麼

- **AI 整合落地** — 將 LLM、agent、自動化流程實際嵌進既有產品，處理串接、成本控制與維運
- **Web Application 開發** — 從零打造，或接手既有系統重構
- **前端與全端開發** — 介面、API、資料層一起負責

## 技術棧

以 **React** 與 **TypeScript** 生態圈為主：

`React` · `TypeScript` · `Next.js` · `Node.js`

## 開源

我們把日常在用的工具開出來。

**[agent-skills](https://github.com/Jeinn-co/agent-skills)** — 給 Claude Code、Codex CLI、Grok Build 用的 agent skills。目前收錄 [`ai-usage`](https://github.com/Jeinn-co/agent-skills/tree/main/skills/ai-usage)：一份指令看完三家 AI 訂閱的即時用量與重置時間。

```bash
npx skills add Jeinn-co/agent-skills@ai-usage
```

**[react-labs](https://github.com/Jeinn-co/react-labs)** — React 與 TypeScript 生態圈的練習與範例集合。
